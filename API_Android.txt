TÀI LIỆU HƯỚNG DẪN GỌI API CHO DỰ ÁN HEALTH & FITNESS ANDROID
Base URL chính thức trên Cloud: https://android.akiya.io.vn/
Content-Type chung: application/json
================================================================================

--------------------------------------------------------------------------------
1. ĐĂNG KÝ TÀI KHOẢN (REGISTER)
--------------------------------------------------------------------------------
- Mô tả: Tạo tài khoản mới trên hệ thống và nhận về mã định danh duy nhất (userId).
- Method: POST
- Endpoint: /api/auth/register
- URL đầy đủ: https://android.akiya.io.vn/api/auth/register
- Headers:
    Content-Type: application/json

- Request Body (JSON):
{
  "username": "nguyenvanA",
  "password": "123456"
}

- Response Thành công (200 OK):
{
  "success": true,
  "message": "Đăng ký thành công!",
  "userId": "USR_a1b2c3d4"
}

- Response Thất bại (400 Bad Request):
{
  "success": false,
  "message": "Tên đăng nhập đã tồn tại."
}

- Ví dụ lệnh cURL để test nhanh trên Terminal:
curl -X POST "https://android.akiya.io.vn/api/auth/register" \
     -H "Content-Type: application/json" \
     -d '{"username": "nguyenvanA", "password": "123456"}'


--------------------------------------------------------------------------------
2. ĐĂNG NHẬP (LOGIN)
--------------------------------------------------------------------------------
- Mô tả: Xác thực tài khoản và lấy về userId để lưu vào SharedPreferences trên Android.
- Method: POST
- Endpoint: /api/auth/login
- URL đầy đủ: https://android.akiya.io.vn/api/auth/login
- Headers:
    Content-Type: application/json

- Request Body (JSON):
{
  "username": "nguyenvanA",
  "password": "123456"
}

- Response Thành công (200 OK):
{
  "success": true,
  "message": "Đăng nhập thành công!",
  "userId": "USR_a1b2c3d4",
  "username": "nguyenvanA"
}

- Response Thất bại (401 Unauthorized):
{
  "success": false,
  "message": "Sai tên đăng nhập hoặc mật khẩu."
}

- Ví dụ lệnh cURL để test nhanh trên Terminal:
curl -X POST "https://android.akiya.io.vn/api/auth/login" \
     -H "Content-Type: application/json" \
     -d '{"username": "nguyenvanA", "password": "123456"}'


--------------------------------------------------------------------------------
3. SAO LƯU DỮ LIỆU TỪ ANDROID LÊN CLOUD (UPLOAD BACKUP)
--------------------------------------------------------------------------------

- Method: POST
- Endpoint: /api/sync/upload
- URL đầy đủ: https://android.akiya.io.vn/api/sync/upload
- Headers:
    Content-Type: application/json

- Request Body (JSON):

    "age": 25,

}

- Ví dụ lệnh cURL để test nhanh:
